The real NASA science behind this game

When the game starts, it asks NASA’s open API for the last 30 days of solar flares from DONKI (Space Weather Database Of Notifications, Knowledge, Information). Moderate (M) and strong (X) flares become your nightly events.

The banner under “Space weather ahead” always says whether data is LIVE or a SNAPSHOT. If NASA can’t be reached or rate limits hit (the shared DEMO_KEY is limited), the game uses a saved list of real past events instead and says so.

Hazard levels (1-5) come from flare class: C and below = 1, M = 2 (M5+ = 3), X = 4 (X5+ = 5). That is a game simplification, not a measured radiation dose. Damage numbers are made up for teaching. Event sizes follow NOAA scales.
